Block theme for Kresge Carpentry LLC.

== Description ==

A one-page site for a carpentry business: hero, services, recent work, process, testimonial, FAQ and contact. Homepage sections are locked patterns, so text and photos can be edited without breaking the layout.

Works with the Kresge Core plugin, which provides Projects and Settings → Business details. Without it, the Work section is empty and contact links show placeholder text.
